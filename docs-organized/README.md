## 📝 Maintenance Guidelines

### Adding New Documentation
1. **Reports**: Place in appropriate `reports/` subdirectory
2. **Guides**: Add to `guides/` with descriptive names
3. **Roadmaps**: Update or add to `roadmaps/`
4. **Fixes**: Document in `fixes/` with issue reference

- Update this README when adding new categories
- Archive outdated docs to `legacy/`

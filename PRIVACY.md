# Privacy Policy (Project Repository)

This open-source project does not collect personal data by default. When you run the software locally, data remains on your machine unless you explicitly configure integrations.

## What We Do

- Local-first operation; no telemetry by default.
- Optional telemetry and federation features are gated behind environment flags (e.g., AETHERRA_OFFLINE, AETHERRA_QUIET, hub telemetry endpoints).
- Logs are local unless you configure remote services.

## Third-Party Services

If you enable providers (e.g., OpenAI, Anthropic, Ollama), your prompts and data may be sent to those services per their policies. Review provider terms and privacy policies before enabling.

## Data Security

- Keep API keys secret; follow SECURITY.md guidance.
- Use local models when privacy is a priority.

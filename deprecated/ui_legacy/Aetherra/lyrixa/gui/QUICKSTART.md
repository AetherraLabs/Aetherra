# Lyrixa GUI

**Status**: 🚧 In Development

A modern, futuristic GUI for the Aetherra Lyrixa AI system.

## Quick Start

```powershell
cd "d:\Aetherra Project\Aetherra\lyrixa\gui"
npm install
npm run dev
```

Visit `http://localhost:3000`

## Key Features

✨ **Aetherra-branded Design** - Teal flame vibe with "CODE AWAKENED" tagline
🎛️ **Comprehensive Dashboard** - System health, metrics, and quick actions
💬 **Chat Interface** - Real-time messaging with Lyrixa
🧠 **Memory Visualization** - QFAC/Concept/Episodic insights
🤖 **Agent Monitoring** - Capability registry and task flows
⚡ **Kernel Status** - Queue metrics and performance monitoring
🌀 **STORM Panel** - Shadow mode with advanced analytics
🔧 **Self-Improvement** - Approve/deny suggestion workflow
📊 **Real-time Charts** - Throughput and latency visualization
🎨 **Interactive UI** - 3D holo-core, particle effects, animations

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Recharts
- React Three Fiber

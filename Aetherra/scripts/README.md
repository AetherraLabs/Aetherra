# Aetherra Scripts

This directory is retained only for signed Aether Script assets that are still
covered by script verification and runtime discovery paths.

Legacy Python cleanup utilities were removed from this package-level directory.
Current repository maintenance tooling belongs under the root `tools/` tree and
must follow Guardian/Security/Self-Incorporation governance boundaries before
mutating the project.

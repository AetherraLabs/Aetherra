# Aetherra Package Tools

This directory contains package-adjacent support assets that have not yet been
migrated into the root `tools/` tree or active runtime packages.

Current rules:

- Signed `.aether` assets stay in place until verification and runtime discovery
  paths are migrated together.
- Runtime tooling belongs in the root `tools/` tree unless a package-local path
  is required by active imports.
- Historical demonstrations and disabled UI launchers should not be added here.

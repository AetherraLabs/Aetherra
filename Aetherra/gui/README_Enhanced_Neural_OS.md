## 🚀 Quick Start

### Prerequisites

```bash
pip install PySide6 numpy
```

### Launch Options

#### Option 1: Standalone Launcher (Recommended)
```bash
python run_aetherra_os.py
```

#### Option 2: Direct Launch
```bash
python launch_enhanced_neural_os.py
```

#### Option 3: Windows Batch File
```cmd
launch_aetherra_enhanced.bat
```

#### Option 4: Through Main Launcher
```bash
python main.py --enhanced
```

## 🔧 Customization

The neural OS is designed to be highly customizable:

1. **Colors**: Modify the color constants in `aetherra_enhanced_neural_os.py`
2. **Animations**: Adjust timer intervals for different animation speeds
3. **Memory Clusters**: Add new memory types in `LiveMemoryGraphWidget`
4. **Plugins**: Extend `PluginAuraViewerWidget` for new plugin types
5. **Metrics**: Add new consciousness metrics in diagnostics panels

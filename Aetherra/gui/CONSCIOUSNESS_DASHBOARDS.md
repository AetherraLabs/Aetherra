## Quick Start

### Launch Qt Dashboard (Recommended)
```bash
cd Aetherra/gui
python consciousness_launcher.py --consciousness
```

### Launch Web Dashboard
```bash
cd Aetherra/gui
python consciousness_launcher.py --web
```

### Launch Through Main GUI (Alternative)
```bash

```

# Project Governance

This project is maintained by Aetherra Labs and community contributors.

## Roles

- Maintainers: Oversee direction, releases, and triage. Merge PRs.
- Contributors: Propose changes via PRs and issues.
- Security Team: Handles vulnerability reports and coordinated disclosure.

## Decision Making

- Proposals are discussed in issues or discussions.
- Maintainers seek consensus; if needed, a simple majority of maintainers decides.
- Security and legal exceptions may be handled privately due to sensitivity.

## Release Process

- Changes land via reviewed PRs and CI checks.
- Security fixes may be fast-tracked.
- Release notes summarize notable changes and security updates.

## Changes to Governance

- Proposed via PR to this document; subject to maintainer review.

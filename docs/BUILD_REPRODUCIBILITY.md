# Build Reproducibility & Verification (Alpha)

## Goals

- Enable consumers to verify that a published artifact (wheel) matches the source + lock file state.
- Provide deterministic inputs list & hashing procedure.

## Deterministic Inputs

| Input                       | Purpose                                     |
| --------------------------- | ------------------------------------------- |
| `requirements.lock`         | Frozen dependency graph (resolved versions) |
| `licenses_report.json`      | License inventory (post-override)           |
| `sbom.json`                 | Dependency + license snapshot               |
| `integrity-manifest.json`   | Consolidated hashes for verification        |
| Source tree (tracked files) | Build recipe + code                         |

## Hash Manifest Generation

Generated by: `tools/generate_integrity_manifest.py`

Includes SHA256 of:

- Lock file
- License report
- SBOM
- Built artifacts in `dist/` (`*.whl`, `*.tar.gz` if any)

## Verification Workflow Example

```powershell
# 1. Clone the repository at the tagged version
 git clone https://github.com/AetherraLabs/Aetherra.git
 cd Aetherra
 git checkout v0.1.0-alpha.X

# 2. Rebuild artifacts
 python -m pip install --upgrade pip
 pip install -r requirements.txt
 python -m build  # or packaging_smoke.py builds wheel

# 3. Regenerate integrity manifest
 python tools/generate_integrity_manifest.py --dist dist --out local-integrity.json

# 4. Compare hashes
 python - <<'PY'
import json,sys
ref=json.load(open('integrity-manifest.json'))
loc=json.load(open('local-integrity.json'))
ref_map={i['path']:i['sha256'] for i in ref['artifacts']}
loc_map={i['path']:i['sha256'] for i in loc['artifacts']}
missing=[p for p in ref_map if p not in loc_map]
changes=[p for p in ref_map if p in loc_map and ref_map[p]!=loc_map[p]]
print('MISSING',missing)
print('CHANGED',changes)
PY
```

Non-empty `CHANGED` list indicates a reproducibility divergence.

## Current Limitations

- No deterministic timestamp normalization in wheel (build metadata may vary).
- No provenance attestation yet (planned Beta).
- Hash excludes unbuilt transitive sources (only wheel outputs).

## Future Enhancements

- Normalize wheel metadata timestamps.
- Embed integrity manifest hash into annotated tag body.
- SLSA-compatible provenance statement emission.

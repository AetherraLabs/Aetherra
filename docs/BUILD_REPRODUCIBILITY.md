# Build Reproducibility & Verification (Alpha)

## Goals

- Enable consumers to verify that a published artifact (wheel) matches the source + lock file state.
- Provide deterministic inputs list & hashing procedure.

## Deterministic Inputs

| Input                       | Purpose                                     |
| --------------------------- | ------------------------------------------- |
| `requirements.lock`         | Windows/Python 3.13 source-runtime and quality-tool graph |
| `requirements-ci.lock`      | Ubuntu/Python 3.11 CI quality-gate lock     |
| `licenses_report.json`      | License inventory (post-override)           |
| `sbom.json`                 | Dependency + license snapshot               |
| `integrity-manifest.json`   | Consolidated hashes for verification        |
| Source tree (tracked files) | Build recipe + code                         |

## Dependency Audit Scope

The quality workflow audits `requirements-ci.lock` on both pull requests and
main pushes. Its isolated scanner requires complete exact-pin evidence; missing
tools, missing dependencies, invalid output, and findings without confirmed
severity fail the gate. The 182-pin CI lock had no reported vulnerabilities in
the November 19, 2026 audit after targeted dependency updates. This is a dated
advisory result, not a guarantee about future findings.

The November 22 desktop baseline reproduced findings in 36 of its 261 packages.
It also failed fresh resolution: virtualenv 20.31.2 required filelock below 4,
conflicting with the repaired filelock 4.2.1 pin. The previous shared environment
was not evidence that this lock could install.

The desktop migration resolves `requirements.txt` and `requirements/quality.txt`
on Windows/Python 3.13, constraining shared versions with the unchanged CI lock.
The resulting 167-package graph has a separate dated advisory scan with no
reported findings. It uses Pillow 13.0.0 and the same supported retrieval stack
as CI. Unrelated Pyxnat/Nipype, Streamlit and Diskcache entries from the old
freeze are excluded. Optional Qt, quantum, SDK and plugin dependencies remain
separate from this profile; their source is preserved.

See [desktop installation](DESKTOP_INSTALLATION.md) for exact fresh-environment,
lock regeneration and installed-distribution audit commands, and
[the alpha decision](ALPHA_READINESS_DECISION.md) for current verification.
The CI graph, desktop graph and optional package extras have distinct scopes.
A source-checkout installation does not establish a wheel-only installation.

## Hash Manifest Generation

Generated by: `tools/generate_integrity_manifest.py`

Includes SHA256 of:

- Lock file
- CI lock file
- License report
- SBOM
- Built artifacts in `dist/` (`*.whl`, `*.tar.gz` if any)

## Verification Workflow Example

```powershell
# 1. Clone the repository at the tagged version
 git clone https://github.com/AetherraLabs/Aetherra.git
 cd Aetherra
 git checkout v0.1.0-alpha.X

# 2. Rebuild artifacts
 python -m pip install --upgrade pip
 pip install -r requirements.txt
 python -m build  # or packaging_smoke.py builds wheel

# 3. Regenerate integrity manifest
 python tools/generate_integrity_manifest.py --dist dist --out local-integrity.json

# 4. Compare hashes
 python - <<'PY'
import json,sys
ref=json.load(open('integrity-manifest.json'))
loc=json.load(open('local-integrity.json'))
ref_map={i['path']:i['sha256'] for i in ref['artifacts']}
loc_map={i['path']:i['sha256'] for i in loc['artifacts']}
missing=[p for p in ref_map if p not in loc_map]
changes=[p for p in ref_map if p in loc_map and ref_map[p]!=loc_map[p]]
print('MISSING',missing)
print('CHANGED',changes)
PY
```

Non-empty `CHANGED` list indicates a reproducibility divergence.

## Current Limitations

- No deterministic timestamp normalization in wheel (build metadata may vary).
- No provenance attestation yet (planned Beta).
- Hash excludes unbuilt transitive sources (only wheel outputs).

## Future Enhancements

- Normalize wheel metadata timestamps.
- Embed integrity manifest hash into annotated tag body.
- SLSA-compatible provenance statement emission.

# Roadmaps Directory

Purpose: Host active and archived roadmaps and track their doc sync status.

Conventions

- Active roadmaps live under `docs/roadmap/` (keep filenames stable, e.g., `aetherra_quantum_roadmap_v_1.md`).
- When a roadmap is completed (per its Definition of Done), keep it in this directory and add a completion header.
- Add a completion header at the top of the roadmap:
  - `Status: COMPLETE` with the completion date (UTC) and commit/tag if applicable.
- Keep a short “Doc Sync Completed” section listing:
  - Updated files (README, PROJECT_OVERVIEW.md, AETHERRA_MEMORY_SYSTEM.md, QUANTUM_OVERVIEW.md, QFAC_MODE_GUIDE.md, etc.)
  - Gate runs (Verify Docs Consistency, Quality Gates) with dates.

Operational notes

- Verify internal links work after edits. Use relative links within `docs/`.
- If the roadmap defined new endpoints or env vars, ensure `PROJECT_OVERVIEW.md` indexes them.

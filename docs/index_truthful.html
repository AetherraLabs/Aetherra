AI-Native Development Environment

An open-source development environment designed for AI-human collaboration. Aetherra provides tools and interfaces for working with AI assistants in your development workflow.

View on GitHub Learn More

Features

🤖 AI Assistant Integration

Lyrixa AI assistant built into the development environment with support for multiple AI providers including OpenAI, Anthropic, and local models.

🔌 Plugin Architecture

Modular plugin system allowing extensibility and customization of the development environment.

🌐 Cross-Platform

Built with Python, runs on Windows, macOS, and Linux systems.

📝 Natural Language Interface

Experimental Aether Script language for describing development tasks in natural language.

🧠 Memory Systems

Persistent memory and learning capabilities to improve AI assistance over time.

🔓 Open Source

Licensed under GPL-3.0, ensuring the project remains free and open for the community.

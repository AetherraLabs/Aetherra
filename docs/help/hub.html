Using the Live Hub/Task UI

Quick setup

  1. Set your Hub URL (if not localhost:3001):
    localStorage.setItem('AETHERRA_HUB_URL', 'http://your-hub:3001')
  2. If your Hub requires auth, set a token:
    localStorage.setItem('AETHERRA_TOKEN', 'YOUR_TOKEN')
  3. Optional: use EventSource instead of fetch for SSE:
    localStorage.setItem('AETHERRA_SSE_EVENTSOURCE', '1')
    If your server expects token in query, also set:
    localStorage.setItem('AETHERRA_SSE_TOKEN_IN_QUERY', '1')
  4. Reload the page to apply changes.

Watching a task

  • Enter the task ID in the widget and click watch or press Enter.
  • The UI does a quick GET /api/tasks/<id> preflight. If it says unauthorized, set the token.
  • Stream endpoint used by default: POST /api/tasks/<id>/stream with header X-Aetherra-Token if present.
  • EventSource fallback uses: GET /api/tasks/<id>/stream (enable via AETHERRA_SSE_EVENTSOURCE=1 in localStorage). Token can be passed in query if your server supports it.

URL parameters

You can deep-link into the watcher by adding parameters to the URL:

  • ?task=<ID> – auto-start watching this task.
  • &hub=<URL> – set Hub URL (also saved to localStorage).
  • &token=<TOKEN> – set token (saved to localStorage).

Troubleshooting

  • plugins: – or red dot: Hub not reachable. Check AETHERRA_HUB_URL and server is running.
  • task not found: Verify the ID with GET /api/tasks/<id>.
  • unauthorized: Set AETHERRA_TOKEN or disable auth at the server (dev only).
  • stream not available: Ensure the stream endpoint is enabled in Hub config and CORS allows your origin.

Quickstart

  1. Install Python 3.10+ and Git.
  2. Clone the repo and create a virtual environment.
  3. Run the hub server and open the web console.

Commands

python aetherra_hub_server.py
python aetherra_os.py

Key Concepts

  • Aether Script (.aether) — declarative tasks and pipelines.
  • Kernel & Plugins — execution runtime with queues and metrics.
  • Service Registry — discover and register capabilities.

Project layout

  • aetherra_os.py — OS entrypoint.
  • aetherra_hub_server.py — Hub API (plugins, status, metrics).
  • tools/ — verification scripts and quality gates.
  • docs/ — this site; sections/ contains landing pages.

Environment basics

  • AETHERRA_HUB_URL — hub base URL the UI talks to.
  • AETHERRA_TOKEN — token sent as X-Aetherra-Token for protected endpoints.

Run your first .aether

  1. Start the hub: python aetherra_hub_server.py
  2. Start the OS: python aetherra_os.py
  3. Open the docs page and set Hub URL via the widget title (Ctrl+click).
  4. Submit a task and watch it via the widget task watcher.

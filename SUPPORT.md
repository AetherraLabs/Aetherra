# Support

Need help?

- Issues: <https://github.com/AetherraLabs/Aetherra/issues>
- Discussions: <https://github.com/AetherraLabs/Aetherra/discussions>
- Security incidents: [security@aetherralabs.org](mailto:security@aetherralabs.org) (do not file public issues)

## Response Targets

- Security reports: initial response within 72 hours
- Issues: triage within 5 business days
- Discussions: community best-effort

## Commercial/Enterprise

For commercial support or enterprise deployments, contact [security@aetherralabs.org](mailto:security@aetherralabs.org) for referral.

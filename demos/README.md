# Aetherra Demos

This directory is intentionally small.

Retained demo surfaces:

- `run_demo.py` - unified read-mostly demo runner for active Hub/API endpoints.
- `storm_traffic_test.py` - targeted STORM traffic probe referenced by STORM
  integration notes.

Old standalone demonstration scripts were removed because they were not part of
the alpha path, were excluded from quality checks, or depended on retired UI and
runtime assumptions.

See `docs/Demo_Playbook.md` for supported demo commands.
